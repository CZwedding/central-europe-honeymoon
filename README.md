# 2026 中歐冬季蜜月｜旅行網站

## 立即使用

此版本是完整免建置的 HTML/CSS/JavaScript PWA。所有旅行內容已放在 `data.json`（14 天、75 個行程項目、8 段長途交通、9 個住宿區間），網站不需要 npm 或 API 金鑰。核心行程可離線瀏覽。

### 本機預覽

在本資料夾執行：

```bash
python -m http.server 8000
```

瀏覽器開啟 `http://localhost:8000`。請勿直接以 `file://` 雙擊 index.html，否則瀏覽器會阻擋 JSON/PWA 載入。

### 真正用 iPad 使用

將整個資料夾部署至 GitHub Pages、Netlify 或 Cloudflare Pages（必須以 HTTPS 提供服務），以 Safari 打開部署網址後按「分享 → 加入主畫面」。第一次使用請在線上完整載入，待 Service Worker 安裝並快取後才能離線看行程。

### 功能與限制

- 14 天行程、日期切換、完成勾選、收藏、筆記、行前清單、訂票／訂房狀態、住宿資料可儲存。
- 使用瀏覽器 LocalStorage，本機資料不會上傳；清除瀏覽器資料、換裝置或使用無痕模式可能遺失，請定期在「筆記與收藏」匯出 JSON 備份。
- 地圖目前是 Google Maps *搜尋視圖*，未核實 PDF 未提供的經緯度，不是 GPS 精準定位，也沒有生成未驗證的路線。
- 即時天氣 API、背景推播、跨裝置同步及網站線上部署均**尚未實作**。
- Service Worker 僅能快取同來源的網站核心資產，不保證 Google 地圖、遠端字體與遠端照片能離線使用；離線時以系統字體和底色顯示。
- 原始 PDF 有些行程時間使用「早上／下午」而非確切時間，本站保留該粒度；部分描述為忠實整理、非逐字掃描文字，重要時刻請與原始 PDF 對照。
- 12/26 哈修塔特出發行程與 08:31 火車存在衝突，詳見行程頁提示。

## 資料組織

`data.json`：只讀原始旅遊資料；`app.js`：互動及 localStorage 使用者狀態；`style.css`：平板及手機樣式；`sw.js`：離線服務；`manifest.webmanifest`：PWA 主畫面安裝資訊。

原始資料來源：使用者上傳之《2026 中歐冬季蜜月｜完整旅遊手冊 V3.1》，頁面 1–22，交通更新 2026/10/29。

## V2 首頁直列行程與景點照片（2026-11-04）

- 在首頁點擊上方任一天的日期卡片，當日完整時間軸會直接更新在日期列表下方，不切換到其他頁面。
- 每個行程卡片均有參考照片區塊。網站在有網路時使用維基百科公開 API 取得相關地標／城市照片；照片不是 PDF 附圖，也不保證為同一個拍攝角度。找不到照片時顯示清楚的提示，不使用假照片。
- 參考照片依賴外部網站與網路，無法保證離線出現。原始行程資料、完成狀態及筆記仍可由本機保存。

### GitHub Pages 更新方式

這次下載的 `central-europe-honeymoon-v2-github-ready.zip` 解壓後，直接選擇其中 **所有檔案以及 assets 資料夾**，上傳到 GitHub 儲存庫最外層（與原 `index.html` 同一層）。GitHub 若要求取代舊檔案，接受取代並提交。不要把 ZIP 本身或解壓後多一層的資料夾上傳。更新後在 Safari 重新開啟頁面，必要時重新整理以啟用新版 Service Worker。
